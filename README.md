<h1 align="center">Web3 WebSocket Client</h1>

<p align="center">
  <b>Lightweight and reliable WebSocket client for blockchain networks with real-time data streaming on Windows.</b>
</p>

---

## What This Tool Does

- Connects to any WebSocket endpoint
- Subscribes to events, logs, and pending transactions
- Supports standard subscription methods
- Auto-reconnect on connection loss
- Message filtering and parsing
- Logs and saves incoming data
- Multiple connection profiles
- Export data to JSON and CSV
- Works on Windows 10 and Windows 11

Web3 WebSocket Client is a professional tool for developers and researchers who need reliable WebSocket connections to blockchain nodes. It supports event subscriptions, auto-reconnect, data logging, and multiple connection profiles. This is a fully functional application with no limitations.
